# 地点的进出

<!-- nav:start -->

[English](../en/places-in-and-out.md) · **简体中文** · [指南目录](README.md)

<!-- nav:end -->

一份存着地点的文件可以变成笔记，Base 匹配到的笔记也可以再变回文件。两个方向都在
仓库内部完成，写出去的坐标一律是 WGS-84，与你当时看的是哪张底图无关。

## 把文件里的地点导入成笔记

在文件列表里右键一个 `.kml`、`.gpx` 或 `.geojson`（笔记的 ⋮ 菜单里也有），选
**把地点导入成笔记…**。手机上文件列表里的这个菜单由长按打开，⋮ 菜单还在原处。

对话框会告诉你这个文件里有多少个地点、前几个叫什么，并让你选一个目标文件夹，默认
是文件旁边、以文件名命名的一个文件夹。确认之前不会写任何东西。

每个地点变成一篇笔记：

```markdown
---
coords: 31.230400,121.473700
---

晚上去。记得点套餐。
```

坐标写进设置 →**在地图中打开**→**坐标属性**里那个属性，格式和这个插件其他所有命令写出来的
一样。地标自己的名字成为笔记文件名，描述成为正文。

在一百家餐厅上跑之前，有几条规则值得先知道：

- **只导入点。** 同一个文件里的轨迹和区域不动 —— 有笔记链接这个文件时它们本来就
  已经画出来了。
- **不覆盖任何东西。** 名字被占了就加数字后缀，两个 `Home` 地标会变成 `Home` 和
  `Home 2`。
- **名字会被清理。** 文件名不能带的字符换成空格；完全没有名字的地标按来源文件和它
  在文件里的位置命名，比如 `restaurants 7`。
- **描述以纯文本落地。** 地图 App 往 KML 描述里写的是 HTML；进到笔记里的是它渲染出
  来的文字，保留换行，不带标记。
- **文件夹就是撤销键。** 导入创建的东西全在里面，删掉这个文件夹就等于撤销这次导入。
- **这是一次快照，不是同步。** 以后再导入同一个文件，会生成新的一份笔记，而不是更
  新原来那份。

从这一刻起它们就是普通笔记了。想在地图上看到它们，用一个 Base 指向这个文件夹 ——
最短的那种 Base 见[快速开始](getting-started.md)。

## 把 Base 地图上的地点导出成文件

在地图上右键（手机上长按），选**导出地点…**。

导出的正好是地图上显示的那些：Base 匹配到、并且坐标解析成功的那些行。一个匹配
16000 篇笔记、其中 300 篇有坐标的 Base，导出 300 个地点。

| 格式 | 内容                 | 用途                           |
| ---- | -------------------- | ------------------------------ |
| GPX  | 途经点               | 手表、GaiaGPS、各类徒步 App    |
| KML  | 地标                 | Google 我的地图、Google Earth  |
| CSV  | 一行一个地点，带表头 | 表格软件，以及任何读表格的东西 |

**用什么给地点命名**决定导出的名字，默认是笔记的文件名，同时把 Base 显示的每个属性
都列出来 —— 笔记名字是 `20250405162700`、地点名在属性里的时候特别有用。某篇笔记这
个属性是空的，那个地点仍然用文件名，所以不会有没名字的地点。

**存成**是仓库里的一个路径。文件夹不存在会自动建；路径已经被占用时导出不会进行，也
不会覆盖那里的文件；写完之后会告诉你写到了哪里。

CSV 里还带着每个地点对应的笔记路径，表格可以顺着它回到笔记。GPX 和 KML 带的是名字
和坐标，也就是读它们的设备期待的东西。

文件落在仓库里，有两个后果：

- 你可以像对待仓库里任何文件一样同步它、分享它、用别的 App 打开它。
- 仓库里的 `.gpx` 和 `.kml` 也是**这个插件**会读的文件。如果有笔记链接它，它就会被
  画出来。不想被画的话，导出到 Base 匹配不到的地方。

## 坐标是笔记自己的值

导出写的是笔记里存的值，不是地图上画的位置。在 GCJ-02 或 BD-09 底图上，图钉会被移
动大约 500 米以对齐瓦片 —— 把画出来的位置导出去，等于把这个偏移永久烧进文件里。同
一个 Base，在高德底图上导出和在 OpenStreetMap 上导出，得到的文件逐字节相同。

进来的方向同理：从文件读到的坐标原样写进笔记，因为轨迹文件本身就是 WGS-84，读它的
过程里没有地图参与。坐标系设置管什么、不管什么，见[坐标与地图服务](coordinates-and-services.md)。

## 支持的文件与链接

| 输入     | 支持形式                               | 提供什么                                       |
| -------- | -------------------------------------- | ---------------------------------------------- |
| 照片     | JPG、JPEG、PNG、WebP、HEIC、HEIF、AVIF | GPS 点、可用时的缩略图、时间和方向元数据       |
| 轨迹     | GPX、GeoJSON、KML、TCX                 | 路线、途经点、标记、箭头和源数据支持的内联统计 |
| 区域     | GeoJSON 和 KML 面                      | 带边界、保留洞的填充区域                       |
| 笔记附件 | 正文普通链接、嵌入、属性文件链接       | 解析后按文件去重的轨迹和照片                   |

支持的照片或轨迹文件也可以直接成为 Base 结果。只有实际轨迹嵌入会创建内联地图；普通链
接和属性链接只在 Base 或周围地图上绘制，不会在笔记中再生成一张地图。

## 设置在哪里

**设置 → 第三方插件 → Advanced Maps** 打开后是十个入口，一个主题一个。点进去才是具
体选项；入口上会直接写着当前设的是什么，常问的那几个不用点开就能看到。

| 入口           | 里面是什么                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------------- |
| 坐标系         | 内联地图和没有单独设置的视图默认用哪个坐标系                                                                   |
| 离线底图       | 磁盘上可以拿来当底图的那几套瓦片、每套覆盖的层级范围，以及默认用哪一套                                         |
| 在地图中打开   | Base 文件、视图名称、打开方式、坐标属性与地名属性、缩放级别、「周围」视图名称、菜单项名称                      |
| 地图按钮       | 地图上带不带跟随和测距按钮，以及跟随的初始状态                                                                 |
| 用外部地图打开 | 内置的几个地图应用，以及你自己添加的                                                                           |
| 地点搜索       | 搜索源；选高德时还有 key 存在哪                                                                                |
| 定位           | 设备定位与自动填写坐标                                                                                         |
| 图钉           | 笔记自身的标记怎么表现                                                                                         |
| 轨迹           | 颜色、线宽、透明度、缩放上限、内联高度、统计、高程剖面、轨迹标记，以及**轨迹属性**——统计命令写出来的属性叫什么 |
| 照片           | 照片图钉、缩略图、照片坐标系，以及照片索引                                                                     |

本指南提到的任何一项，也都可以直接在设置搜索里搜到——它照样能搜到这些页面里面的行。

## 哪项设置决定什么

| 问题                           | 由什么决定                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------ |
| 哪些笔记或直接文件参与？       | Base 筛选器                                                                                      |
| 笔记图钉长什么样？             | Base 公式和地图视图的 **Marker icon**/**Marker color** 选项                                      |
| 笔记坐标在哪个属性？           | 地图视图的 **Marker coordinates** 属性                                                           |
| 哪个 Base 驱动导航与周围视图？ | Advanced Maps 的 **Base 文件**和**视图名称**设置                                                 |
| 某张地图怎样画轨迹或换算底图？ | 存在时使用 `trackWeight`、`trackOpacity`、`fitMaxZoom` 和 `coordSystem` 视图键，否则使用插件设置 |
| 某张地图打开时用哪个底图？     | `offlineTiles` 视图键；那几套瓦片本身是插件设置                                                  |

## 使用边界

- Advanced Maps 依赖第一方 Maps 视图。它不可用时，插件会说明或跳过增强，让宿主保持可
  用。
- 没有可读 GPS 的照片仍是 Base 结果，但没有地图图钉。带定位但没有可用缩略图的照片仍
  有圆点。
- 指向外部相册的目录链接属于桌面文件系统设置。每台桌面设备都要建立对应链接；云端文件
  要保持本机可读，避免链接循环，并确认备份和同步服务如何处理链接。移动端不能复用桌面
  链接。
- 周围视图仍然服从 Base 筛选条件。嵌入会保存视图名，所以重命名视图后也要更新已有嵌入。
- 在普通标签页打开配置好的 Base，视图选项可以写回 Base 文件；弹窗不打乱布局，但没有地
  方写回这些改动。

## 什么会离开你的库

笔记、轨迹和照片内容不会自行离开。插件没有遥测、更新检查或自己的服务器。

| 什么时候           | 出去的是什么                           | 去哪里             |
| ------------------ | -------------------------------------- | ------------------ |
| 地图显示在屏幕上   | 瓦片请求：你的 IP 与查看区域           | 选中的底图服务     |
| 地图画的是本地瓦片 | 不发送任何内容；瓦片从磁盘读取         | —                  |
| 搜索地点           | 搜索词、语言和配置的 key               | 选中的地理编码服务 |
| 反向解析坐标       | 你请求的那一个坐标                     | 选中的地理编码服务 |
| 打开外部地图       | 点击的坐标                             | 你选择的地图应用   |
| 使用设备定位       | 插件不发送任何内容；位置由操作系统提供 | —                  |

搜索 key 可以放进 Obsidian secret storage，让它不进入同步的插件设置；也可以为了跨设备方
便放在插件设置里。无论存在哪里，请求服务商都会在查询时收到它。

# 周围视图与导航

<!-- nav:start -->

[English](../en/around-and-navigation.md) · **简体中文** · [指南首页](README.md)

<!-- nav:end -->

一个 Base 能做三件事：画出当前笔记周围的笔记、在完整集合里打开某篇笔记、跟着你切换
笔记走。在**在地图中打开**里配置一次，三件事都用同一个 Base。

Base 是 Obsidian 里用来收集文件的一种文件：你写筛选条件，它把命中的笔记和文件显示成
表格或地图。

## 只显示本篇周围的笔记

先在 Advanced Maps 设置的**在地图中打开**里，用 **Base 文件**选好要复用的 Base，再
运行**插入本篇相关笔记的地图**。命令会给这个 Base 补上一个「周围」地图视图（如果还没
有），并插入：

```markdown
![[places.base#周围]]
```

周围视图只保留三类笔记：

- 放置这段嵌入的本篇笔记；
- 本篇链接到的笔记；
- 链接到本篇的笔记。

这些笔记链接的轨迹和照片照常绘制。一篇旅行索引可以短到这样：

```markdown
# 西湖周末

[[断桥]]
[[雷峰塔]]
[[灵隐寺]]
[[weekend.gpx]]

![[places.base#周围]]
```

`weekend.gpx` 前面没有 `!`，所以正文里只有一张周围地图，轨迹画在这张地图上。给它加上
`!`，链接下面就会多出第二张独立的地图。

![一篇游记里的普通双链被渲染成内嵌周围地图上的图钉](../../images/around-map.png)

周围视图不会带回来被 Base 筛掉的笔记：你的筛选条件仍然算数。嵌入里保存了视图名，所以
重命名视图后，已经写进笔记的那些嵌入也要跟着改。

在设置 → **在地图中打开**里把**插入相关笔记的地图**关掉，编辑器的右键菜单里就没有本
插件的这一项，命令也从命令面板消失。已经插进笔记里的地图照常绘制——关掉的是「再插入
一张」这个入口，不是已经画出来的图。

## 一个 Base，处处复用

在 Advanced Maps 设置 → **在地图中打开**里指定一次 **Base 文件**和**视图名称**，同一
个 Base 就同时供「在地图中打开」、跟随当前笔记和周围嵌入使用。

| 问题                         | 由什么决定                                                  |
| ---------------------------- | ----------------------------------------------------------- |
| 哪些笔记或直接照片文件参与？ | Base 筛选器                                                 |
| 笔记图钉长什么样？           | Base 公式和地图视图的 **Marker icon**/**Marker color** 选项 |
| 笔记坐标在哪个属性？         | 地图视图的 **Marker coordinates** 属性                      |

## 在这张地图中打开当前笔记

带坐标属性（默认 `coords`）的笔记，菜单里会出现**在地图中打开**。它打开你配置好的
Base，把镜头移到这篇笔记，并弹出它的气泡。

**打开方式**决定在哪里打开：普通标签页会打开 Base 文件本身，你在地图上改的视图选项会
被保存；弹窗则不打乱当前布局，但改动没有地方写回去。

在同一页把**在地图中打开笔记**关掉，任何笔记的菜单里都不会再有这一项，命令也一起从命
令面板消失。上面配置的 Base 文件照旧留着——「插入相关笔记的地图」用的还是它。

![配置好的 Base 地图打开在一篇笔记上，周围其他地点仍然可见](../../images/open-in-map.png)

## 跟随当前笔记

点「缩放到全部」旁边的 ⊹，这张地图就会跟着你切换笔记。它保留当前缩放级别，也不会改写
Base 的查询条件。

设置 → **地图按钮**里的**新地图默认跟随**决定刚打开的地图上这个按钮朝哪边；地图关掉后
不会记住这个选择。在同一页把**跟随当前笔记**关掉，按钮就没了——已经打开的地图和后开
的都一样。

![一篇笔记与 Base 地图并排，地图正在跟随笔记并打开它的气泡](../../images/follow-active-note.png)

## 测距

点 ⊹ 下面的尺子按钮，地图就变成一把尺。点一下放一个点，第一个之后的每个点旁边都标着
从起点算起的距离。桌面端还有一条虚线跟着鼠标走，上面是加上这段后的总数；尺子旁边展开
↺ 或 **Backspace** 撤销上一个点。再点一次尺子，读数会收起来，测量本身还留在地图上；
再点一次又展开，显示的是到那时为止量到的数。收着的时候照样可以继续放点。

✕ 或 **Esc** 才是收起尺子。全程不往任何笔记里写东西，收起之后这次测量就没了。

在设置 → **地图按钮**里关掉**测距**，尺子按钮就一起消失。

![Base 地图上画着一条三个点的测量线，每个点都标着从起点算起的距离，总数在尺子按钮旁边展开](../../images/measure-distance.png)

尺子拿出来的时候，点击归它所有：点在图钉上是加一个点，而不是打开那篇笔记，也不会有气
泡挡住正在量的地面；双击是放两个点，而不是放大。手机上的点按同样归它，连点两下也是放
两个点。

把鼠标挪到地图上已有的某个东西附近，那个东西上会出现一个圈——笔记的图钉、轨迹的途经
点或起终点图钉、照片的位置，或者这次测量里你早先放下的点。这时点击，落下的是那个东西
自己的坐标，而不是你点中的那个像素。所以「这篇笔记离那张照片多远」是准的，一圈路线也
能正好收在起点上。刚放下的那个点不会被吸附，因为从一个点量到它自己没有意义。按住
**Alt** 再指、再点，就完全不吸附，量的就是那块地面本身。

![一次测量的过程：指针靠近图钉时那个点上出现一个圈，量出来的一段跟着指针走并实时报距离，每次点击都把点落在那个东西自己的坐标上](../../images/measure-snap.gif)

手机上落点同样会吸到那个东西自己的坐标，但没有圈可以照着瞄——那个圈是悬停画出来的。
把手指点在标记、途经点或照片本身上，而不是它附近。**Alt** 在手机上没有对应的操作，所
以要量某个东西旁边的空地，就点得离它远一点。

尺子量的是你点的那几个地点之间的直线距离，不是沿路走的长度。要后者就把路线存成轨迹
文件，读[它的数据](tracks-and-areas.md)。在国内底图上，尺子量的是偏移瓦片背后真实的
坐标，所以中途换底图，测量结果不会跟着变。

## 位置重合的图钉

放大到足够近时，坐标完全相同的笔记会散成一圈，让每个图钉都能单独挑出来打开，用鼠标或
用手指都一样；缩小后又合回它们真实的共享位置。笔记不会被改写，复制出来的坐标也不变。
**散开重合的图钉**可以关闭这个效果。
